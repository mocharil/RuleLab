# Screenshot aplikasi RuleLab 0.5

Screenshot berasal dari aplikasi berjalan di mode demo (SQLite, tanpa LLM). Desktop 1440x1100, ponsel 390x844. Angka A/B merupakan model asumsi, bukan hasil pengukuran empiris. Screenshot editor mencakup form simulasi, hasil simulasi, tampilan ponsel, serta review inline. Empat menu lain disertakan dalam desktop dan ponsel. Screenshot viewport menampilkan bagian layar saat diambil; panel asisten dapat di-scroll pada desktop.

Validasi: 39 tes backend, 29 alur browser lolos. Lihat docs/TEST_REPORT.md dan scripts/browser_smoke.cjs untuk cakupan dan batas pengujian.

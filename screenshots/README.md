# Screenshot versions

Existing folders v0.4–v0.7.1 contain historical browser captures. They do not show the current RuleLab 1.0 remake.

No current-version screenshot was captured in this environment because Chromium cannot start. Run `npm install`, `npx playwright install chromium`, then `npm run screenshots` locally. The runner writes actual new captures and a report to `screenshots/v1.0/` using an isolated demo database.


Versi 1.2 menambahkan Galeri dokumen dan bot. Belum ada screenshot browser aktual untuk versi ini. Jalankan `npm run screenshots` untuk menangkap UI demo terbaru ke `screenshots/v1.2`.

Versi 1.3 menerapkan TasteSkill. Capture runner menghasilkan screenshot lokal di screenshots/v1.3. Belum ada verifikasi browser aktual versi ini pada lingkungan pembuatan paket.

# Prompt desain RuleLab 1.0

Refine RuleLab as a working product for Indonesian regulatory drafting and review. Preserve white surfaces, a cool neutral canvas and restrained crimson accents. The product should feel precise and calm, with a recognisable legal document surface and practical inspection tools.

Use Manrope for interface and legal body text. Reserve Cormorant Garamond for document titles and an editorial landing accent. Use 5–12px corner radii, quiet borders, minimal shadows and clear alignment. Keep the supplied RuleLab mark.

Use task-specific composition. The dashboard is a work queue and draft collection. The editor is a document with an adjacent assistant, and supports a focus mode. Conflict review shows evidence and proposed text. Impact comparison clearly separates inputs, assumptions and results. The social simulation is an interactive map of actual persona replies, with a readable transcript and a context inspector. The library is a document list. History is an inspectable timeline. Agents have visible execution steps.

Avoid generic oversized hero cards inside tools, repeated ornamental illustrations, sparkle icons, gradient cards, decorative charts, glowing borders, constant shimmer, glass blur and invented statistics. A visual must explain data, relationships, status or an action. Do not copy reference dashboards' colours or their fake metrics.

Preserve all existing functions and action bindings: draft CRUD, optimistic version guards, import, DOCX export, legal review, search/compare, scenario simulation, agent jobs, cancellation, history and reviewer notes. Editor input must survive sidebar folding, tours, assistant tabs, focus mode and recoverable failures.

Use Indonesian labels that name actions. Headings describe the task. Display only actual saved versions, counts, source quotations and executed events. The initial social screen shows configured personas and clearly says no opinions exist yet. Demo templates, live AI, replay, assumption models and public opinion must remain distinct.

Support keyboard focus, native/Radix dialogs, reduced motion, labelled controls and mobile navigation for every menu. Keep critical text readable and give status labels in addition to colour. Guides are available on demand and should not displace the task.

Keep React + TypeScript + Tailwind + Radix + Motion for components and the existing FastAPI and legal workflow modules. No new login or SSO is needed for the hackathon. Ship a local production bundle so runtime has no npm/CDN requirement.
